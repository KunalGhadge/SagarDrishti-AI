# Changelog

All notable changes to the **SagarDrishti AI (ORCA)** Marine Intelligence & Decision Support Platform (Team WE# / SIH 2026 / ISRO PS 26176) are documented here.

## [1.0.0] - 2026-08-31
### Added
- **Multi-Agent Orchestration Engine**: Autonomous supervisor coordinating specialized marine agents (IMD Weather & Cyclone, INCOIS PFZ Bio-Optics, IMO FSA Maritime Safety, and Policy News).
- **Critical Maritime SOS Distress Protocol**: Immediate Code Red escalation for piracy, vessel sinking, armed threats, and emergency distress calls with live ICG MRCC (1554), VHF Channel 16, and EPIRB 406MHz instructions.
- **Ocean Physics Ingestion Workflow**: Live real-time wave height, swell period, and current velocity ingestion from Open-Meteo Marine Physics API with Douglas Sea State and IMO FSA risk classification.
- **Marine Model Context Protocol (MCP) Hub**: 8 specialized oceanographic MCP connectors (ISRO MOSDAC, IMD Cyclone, INCOIS PFZ, AIS Tracking, Open-Meteo Marine, IMO FSA, Indian Coast Guard Policy, GEBCO Bathymetry).
- **Multilingual Support**: Real-time localization across 10 Indian coastal languages (Hindi, Marathi, Gujarati, Tamil, Telugu, Malayalam, Bengali, Odia, Kannada, English).
